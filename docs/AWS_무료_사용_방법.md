# AWS(아마존 클라우드) 무료로 쓰는 방법

> 2026-11-09 기준. AWS 정책은 바뀔 수 있으니 가입 전에 [AWS 무료 티어](https://aws.amazon.com/free/) 페이지를 다시 확인한다.

"평생 무료"는 아니고, 신규 가입 크레딧과 항상 무료 서비스를 조합해서 쓰는 방식이다. 예전의 "12개월 무료" 제도는 2025년에 없어졌다.

## 1. 신규 가입 크레딧 (가장 일반적인 방법)

- **크레딧:** 가입하면 100달러를 바로 받고, 과제 5개를 하면 개당 20달러씩 최대 100달러를 더 받는다.
  - EC2 서버 켜고 끄기
  - Lambda로 간단한 앱 만들기
  - Bedrock에서 AI 모델 써 보기
  - RDS 데이터베이스 만들기
  - 예산 알림(AWS Budgets) 설정
- **기간:** 6개월이 지나거나 크레딧을 다 쓰면 끝난다.
- **요금 걱정:** Free 플랜으로 가입하면 크레딧을 넘어도 요금이 청구되지 않는다. 대신 기한이 끝나면 계정이 자동으로 닫힌다. 계속 쓰려면 유료 플랜으로 전환해야 하고, 그때부터는 쓴 만큼 청구된다.
- **조건:** AWS 계정을 처음 만드는 사람만 받을 수 있다. 카드 등록은 필요하다.

## 2. 항상 무료인 서비스 (기간 제한 없음)

30개가 넘는 서비스가 월 한도 안에서는 크레딧과 별개로 계속 무료다.

- **Lambda:** 월 100만 회 요청까지
- **DynamoDB(데이터베이스):** 25GB까지
- **SNS·SQS(알림·메시지):** 월 100만 건까지

해커톤 대시보드라면 백엔드를 Lambda로 만들어 거의 0원으로 돌릴 수 있다. 돈이 드는 부분은 사실상 Claude 호출(Bedrock)인데, 이건 크레딧에서 빠진다.

## 3. 그 밖의 경로 (조건이 맞으면)

- **교육과정·주최 측 제공 계정:** POSCO K-뉴딜 아카데미 같은 교육과정이나 해커톤 주최 측이 AWS 계정이나 크레딧을 주는 경우가 많다. 운영진에게 먼저 물어본다. 내 카드를 걸지 않아도 되는 가장 깔끔한 방법이다.
- **AWS Educate:** 학생과 교육용 프로그램으로, 실습 환경을 무료로 제공한다. 쓸 수 있는 서비스가 제한돼서 실제 서비스 배포용으로는 부족할 수 있다.
- **AWS Activate:** 스타트업용 크레딧 프로그램이다. 공식 안내상 Free 플랜 계정은 신청할 수 없고 유료 플랜이어야 한다.

## 요금 폭탄 피하는 방법

1. 가입할 때 **Free 플랜**을 고른다. 실수해도 청구되지 않는다.
2. **예산 알림**(예: 월 5달러)을 바로 설정한다.
3. 다 쓴 EC2 서버나 RDS 데이터베이스는 꼭 삭제한다. 켜 두기만 해도 크레딧이 줄어든다.
4. Claude를 연결한 공개 주소에는 비밀번호나 요청 횟수 제한을 건다.

## 이번 프로젝트(Steel_Connect)에 권하는 조합

1. 먼저 교육과정에 제공 계정이 있는지 물어본다.
2. 없으면 신규 가입 크레딧(최대 200달러)과 Lambda 무료 한도로 만든다.

이 정도면 해커톤 기간 동안 비용 없이 충분히 쓸 수 있다.
