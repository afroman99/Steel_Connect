## 프로젝트 개요

우리 팀은 탄소 감축 목표와 현재 생산 조건을 입력하면, 필요한 전력과 비용을 계산하여 조건에 맞는 대안을 제시하는 AI 웹앱을 구현했다. 설비 계획 담당자와 에너지 조달 담당자가 같은 결과를 보며 어떤 공정이 효율적인지 파악하도록 돕는 것이 목적이다.

탄소 목표 및 상황 입력 → 요구 전력 및 비용 계산 → 가장 적합한 대안 제시

AI는 질문을 이해하고 계산 도구를 선택한다. 숫자는 파이썬 시나리오 계산식을 산출한다. 웹앱은 그린수소 에너지와 일반 전력 에너지 중에서 적합한 부분을 판단한다. 이에 대한 전력 필요량 및 경제성을 계산하여 어시스턴트 결정에 대한 근거를 확인한다.

| 핵심 질문 | 제공하는 결과 |
|---|---|
| 목표만큼 탄소를 줄이려면 무엇이 필요한가 | 전체 전력량과 필요한 무탄소 전력량 |
| 확보한 전력으로 목표를 달성할 수 있는가 | 확보량 대비 부족분과 변경할 조건 |
| 어떤 방법이 입력 조건에 더 적합한가 | 공정별·전력 조달별 비교와 추천 이유 |

주요 성과는 계산 도구 12개, 자연어 웹앱 연결, 평가 질문 50개 구축이다. 공개 자료 기반 조건부 계산을 구현했으며, 사내 데이터와 내부 서버를 활용하는 단계는 향후 확장 방향이다.

## 1. 문제 정의와 프로젝트 목적

### 탄소 감축에는 전력 준비가 중요

고로는 석탄 계열 환원제를 이용해 철광석에서 산소를 제거한다. 이 과정에서 이산화탄소가 발생한다. 수소환원제철은 수소로 산소를 제거해 물을 생성하고, 환원된 철을 전기로에서 녹이는 경로다. 전기로는 철을 녹이는 설비라서 수소환원 단계와 역할이 다르다.

저탄소 공정으로 바꾸면 에너지 구조도 달라진다. 고로 공정에서 발생하는 부생가스는 자체발전에 활용된다. 고로 가동이 줄면 이 에너지원이 줄어들 수 있다. 동시에 수소 생산과 전기로 운영에는 많은 전력이 필요하다.

| 전환에 따라 달라지는 점 | 계획 단계에서 확인할 질문 |
|---|---|
| 수소 생산과 전기로의 전력 소비 증가 | 새로 확보해야 할 전력은 얼마인가 |
| 부생가스를 활용한 자체발전 감소 가능성 | 줄어드는 자체발전을 구매 전력으로 메우면 비용은 얼마인가 |
| 전력을 만드는 방식에 따른 배출 차이 | 같은 공정이라도 어떤 전력을 써야 감축 목표를 달성하는가 |

### 우리 팀이 해결하려는 문제

탄소 감축 목표만으로는 전력 확보 계획을 세우기 어렵다. 생산량, 전력 원단위, 전기요금, 전력 배출계수 등을 함께 계산해야 하기 때문이다. 우리는 이 계산을 한국어 질문으로 빠르게 실행하고, 필요한 준비 조건까지 확인하는 도구를 만들었다.

핵심은 수소환원제철을 무조건 선택하는 것이 아니다. 입력한 탄소 목표를 충족하는지 확인하고, 반영된 비용과 전력 확보 조건을 비교해 유리한 대안을 검토하는 것이다.

### 사용자와 활용 시점

주요 사용자는 설비 계획 담당자와 에너지 조달 담당자로 설정했다. 저탄소를 실현하거나 전력량을 조절하는 상황에서 관리자가 검토하여 활용하는 구상이다. 현업 수요는 업무 가설로 제안했으며, 실제 도입 전에는 담당자 인터뷰와 사내 계산 결과 대조가 필요하다.

## 2. 서비스 이용 흐름과 대안의 의미

### 목표에서 준비 계획으로 이어지는 흐름

| 단계 | 입력 또는 처리 | 사용자가 확인하는 내용 |
|---|---|---|
| 1 목표와 상황 입력 | 탄소 목표 및 전력 요금 가정 | 달성하려는 목표와 현재 조건 |
| 2 요구량과 비용 계산 | 계산 도구로 전력, 배출 비용 산출 | 필요 전력, 예상 비용, 탄소 감축량 |
| 3 목표 충족 여부 비교 | 필요 무탄소 전력과 확보량 대조 | 얼마나 전력이 부족한지 |
| 4 대안과 이유 제시 | 조달 방법 및 공정 조건 비교 | 어떤 대안이 유리하며 무엇을 준비할지 |

### 비교 대상을 두 단계로 구분

첫 번째는 생산 경로 비교다. 전기로 전환과 수소환원제철이 같은 감축 목표를 달성할 때 필요한 생산량과 전력을 비교한다. 원료와 제품 조건까지 동일하다고 가정한 완전한 대체 관계는 아니므로, 결과는 경로를 검토하는 참고값으로 사용한다.

두 번째는 수소환원제철 안에서의 전력 선택이다. 수소를 재생에너지 직접 PPA 전력으로 만들지, 전력망 전력으로 만들지 비교한다. 현재 그린수소 추천 기능은 이 두 수전해 방식을 대상으로 한다. 외부에서 수소를 구매하는 계약의 최적화와는 구분된다.

### 가장 적합한 대안을 제시하는 방식

먼저 입력한 감축 목표를 만족하는지 살핀다. 다음으로 계산에 반영한 전력비용과 탄소 비용을 비교한다. 추천 결과에는 유리한 이유와 결론이 달라지는 조건을 함께 제시한다. 따라서 추천은 입력 조건 안에서의 판단이며, 전체 투자 타당성 평가로 확장하려면 추가 비용 자료가 필요하다.

정보가 부족한 질문에는 필요한 값을 묻는다. 근거가 없는 미래 예측에는 계산 가능한 가정 시나리오를 안내한다. 사용자가 다음에 무엇을 입력하고 확인해야 하는지 알 수 있도록 설계했다.

## 3. 활용 데이터와 분석 준비

공개 데이터의 역할을 나누어 사용했다. 부하 패턴은 UCI 자료로 살펴보고, 제철소의 규모는 포스코 공개 자료로 설정했다. 현재 전기요금과 공정별 전력 원단위는 요금표와 문헌을 적용했다.

| 데이터와 출처 | 분석에 활용한 내용 | 적용 범위 |
|---|---|---|
| UCI 철강 에너지 데이터 | 2018년 15분 간격 35,040행의 부하 패턴 | 포스코 실측이 아닌 방법 시연용 |
| 포스코 ESG Factbook 2024와 에너지 페이지 | 구매 전력 3.05 TWh와 자체생산 비율 85.5% | 국내 사업장 공개 집계 |
| 한전 산업용 요금표와 2026 개편 자료 | 고압 A·B·C와 선택 요금 9종 | 기본 시나리오는 고압 B 선택Ⅲ 가정 |
| 정부 전력배출계수 자료 | 2023년 소비단 계수 0.4173 tCO₂eq/MWh | 평균 전력망 전력의 배출 계산 |
| Vogl 2018과 Bhaskar 2020 | 수소환원 전력 원단위 3.48~3.72 MWh/t | 문헌값이며 HyREX 실측은 아님 |
| Logar 2021과 IPCC 2006 | 전기로 450 kWh/t와 직접 배출 0.08 t/t | 전력값은 예시, 직접 배출은 고철 기반 |
| 전력거래소와 탄소시장 공개 자료 | 시간별 발전 구성·재생발전·탄소 가격 | 조달 조건과 민감도 분석 |

### 자료를 정리하며 확인한 사항

UCI의 기존 시간대 라벨은 2018년 기준이다. 요금 계산에서는 이를 그대로 쓰지 않고 한전 공식 시간표로 다시 분류했다. 결측과 중복을 점검하고 15분 단위 시간 정보를 정리했다.

포스코 Factbook의 집계 범위가 바뀐 점도 고려했다. 같은 기준으로 비교할 수 있는 2023년과 2024년 구간을 중심으로 해석했다. 총 전력 약 21 TWh는 구매 전력과 자체생산 비율을 이용한 역산값이다.

전력배출계수 0.4173은 발전 단계가 아닌 소비단 기준이다. 전기로와 수소환원제철의 탄소 계산에는 같은 기준을 적용하도록 정리했다.

## 4. 계산기와 AI 웹앱 구현

### 계산과 설명을 나눈 구조

웹앱 질문 입력 → AI의 조건 해석 → 계산 도구 호출 → 계산 결과 반환 → AI의 설명과 대안 제시

AI가 수치를 기억해서 답하도록 학습시키는 대신, 검증 가능한 계산 함수를 호출하도록 구현했다. 계산 기준이 바뀌면 코드를 수정해 같은 질문을 다시 계산할 수 있다. 질문 세트는 모델 학습용이 아니라 평가용으로 사용했다.

| 구성 | 구현 내용 |
|---|---|
| 계산 엔진 | 파이썬으로 전력·요금·순 감축과 목표 역산 구현 |
| AI 연결 | Claude Code를 이용한 로컬 연결과 계산 도구 12개 제공 |
| 웹 화면 | React와 Tailwind 기반 채팅 화면 및 결과 창 구성 |
| 대화 처리 | 최근 대화 3회를 연결해 후속 질문의 조건 이해 |
| 결과 표시 | 필요 전력·비용·감축량과 기본 가정·근거 표시 |
| 응답 상태 | 정상 계산 ok, 정보 요청 ask, 지원 범위 안내 refuse |

### 핵심 계산 원리

전력은 생산량에 톤당 전력 사용량을 곱해 구한다. 구매 전력에는 전력배출계수를 적용한다. 순 감축량은 기존 공정을 대체해 줄어드는 배출에서 새 공정의 직접 배출과 추가 전력 배출을 뺀 값이다.

전기로 기본 계산은 기존 공정의 직접 배출 기준 1.99 t/t, 전기로 직접 배출 0.08 t/t, 전력 0.45 MWh/t를 사용한다. 1.99는 회사 평균 자료에서 역산한 대체 기준이며 고로 단독 실측값은 아니다.

수소환원제철은 기본 3.72 MWh/t를 사용한다. 무탄소 전력 비율이 높아지면 전력 사용에 따른 배출이 낮아진다. 자체발전 감소량은 별도 조건으로 입력해 추가 구매 전력에 반영한다.

전기요금에는 기본요금, 계절·시간대별 전력량요금, 기후환경·연료비 조정, 전력산업기반기금을 반영했다. 부가가치세는 사업자 환급을 가정해 제외했다. 현 단계의 AI 연결은 개발자 PC에서 실행하는 시제품이다.

## 5. 대표 사용 사례와 대안 제시

### 탄소 목표와 전력 확보량을 함께 입력

> "수소환원제철로 연간 50만 톤을 생산하고 탄소를 50만 톤 줄이고 싶다. 무탄소 전력은 0.3 TWh를 확보했다. 무엇을 더 준비해야 할까?"

| 계산 항목 | 결과 |
|---|---|
| 전체 필요 전력 | 연간 1.86 TWh |
| 필요 무탄소 전력 비율 | 36.2% |
| 필요 무탄소 전력량 | 약 0.67 TWh |
| 확보한 무탄소 전력량 | 0.30 TWh |
| 추가로 필요한 무탄소 전력량 | 약 0.37 TWh |

계산기는 목표를 이루기 위한 조건을 역으로 구한다. AI는 "무탄소 전력이 약 0.37 TWh 더 필요하다"고 설명하고, 확보량을 늘리는 방법이나 다른 조건을 검토하도록 안내한다.

### 부족분을 해소하기 위한 조건 비교

| 검토 방향 | 한 조건만 바꿨을 때의 계산값 | 해석 |
|---|---|---|
| 전력 추가 확보 | 무탄소 전력 0.30 → 0.67 TWh | 현재 생산량과 감축 목표 유지 |
| 생산 계획 확대 | 연간 생산량 50만 → 약 86만 t | 같은 총 감축 목표를 더 큰 생산량으로 달성 |
| 다른 공정 검토 | 전기로 생산 약 29만 t, 전력 약 0.13 TWh | 원료와 제품 조건을 함께 확인할 대안 |
| 감축 목표 재설정 | 50만 → 약 34.4만 t | 기존 목표 달성이 아닌 계획 변경 |
| 기술·전력망 조건 개선 | 원단위 2,972 kWh/t 또는 계수 0.3173 | 현재 확보량으로 목표를 맞추는 외부 조건 |

각 행은 한 조건씩 바꿔 계산한 결과다. 생산량 확대는 총 생산계획과 설비 한도를 함께 살펴야 한다. 기술과 전력망 변화는 담당자가 바로 조정할 수 있는 값과 구분해 제시한다.

## 6. 그린수소와 전력망 수전해 비교 결과

수소환원제철을 선택하더라도 수소를 어떤 전력으로 만드는지에 따라 결과가 달라진다. 비교 도구는 재생에너지 직접 PPA 수전해와 전력망 수전해의 비용을 계산하여 조건에 맞는 선택을 설명한다.

기본 가정은 전력배출계수 0.4173, 직접 PPA 계약 단가 180원/kWh, 탄소 가격 29,500원/t이다. 그린수소 방식에서도 수전해 외 공정 전력은 전력망에서 공급하는 조건이다.

| 비교 항목 | 전력망 수전해 | 그린수소 방식 |
|---|---|---|
| 쇳물 1t당 순 탄소 감축 | 약 0.44 tCO₂ | 약 1.55 tCO₂ |
| 쇳물 1t당 비용 비교 | 기본 조건에서 약 6.5만 원 낮음 | 탄소 비용을 포함해 약 6.5만 원 높음 |
| 판단의 특징 | 낮은 생산 단위 비용을 우선할 때 검토 | 더 높은 탄소 감축 목표에 대응 |

두 방식의 비용 비교에는 전력비용과 탄소 비용을 반영했다. 같은 것으로 가정한 수전해 설비 투자비는 제외했다. 따라서 현재 조건의 비용 우위와 감축 목표 충족 여부를 함께 설명해야 한다.

### 추천이 달라지는 조건

| 변경 조건 | 모델에서 나타난 갈림길 |
|---|---|
| 탄소 가격 상승 | 약 8.7만 원/t 이상에서 그린수소 방식 유리 |
| PPA 계약 단가 하락 | 약 157원/kWh 이하에서 그린수소 방식 유리 |
| 한전 요금 상승 | 기본 요금 대비 약 14.4% 이상 상승 시 그린수소 방식 유리 |
| 탄소 목표 강화 | 쇳물 1t당 0.44 t를 넘는 감축은 비교한 두 고정 조건 중 그린수소만 충족 |

이 결과는 "항상 어느 방법이 좋다"는 결론보다, 전환 전에 어떤 계약 조건을 준비해야 하는지 보여준다. 계약 단가, 탄소 가격, 배출계수를 바꾸면 같은 계산기로 다시 비교할 수 있다.

## 7. 공정 전환과 전력비용 분석 결과

### 전기로와 수소환원제철의 기본 시나리오

| 시나리오 | 추가 전력 | 연 전력요금 | 순 탄소 감축 |
|---|---|---|---|
| 전기로 250만 t 설비, 가동률 70% | 0.79 TWh | 1,395억 원 | 301만 tCO₂ |
| 수소환원 30만 t 설비, 가동률 70%·전력망 전력 | 0.78 TWh | 조건별 계산 | 9.2만 tCO₂ |
| 같은 수소환원 생산량, 전체 전력 무탄소 | 0.78 TWh | 조달 조건별 계산 | 41.8만 tCO₂ |

전기로는 연간 175만 t, 수소환원제철은 21만 t 생산 조건이다. 생산 규모가 다르므로 위 표의 총량만으로 공정 우열을 정하지 않는다. 수소환원제철의 감축 효과가 전력 조달에 크게 달라진다는 점이 핵심이다.

### 같은 감축 목표로 비교

| 연간 순 감축 100만 t 달성 경로 | 필요 생산량 | 필요 전력 |
|---|---|---|
| 전기로 | 약 58만 t | 약 0.26 TWh |
| 수소환원 전력망 전력 | 약 228만 t | 약 8.5 TWh |
| 수소환원 무탄소 전력 50% | 약 82만 t | 약 3.1 TWh |
| 수소환원 무탄소 전력 100% | 약 50만 t | 약 1.9 TWh |

같은 목표라도 필요한 전력이 크게 달라진다. 현재 기본 가정에서는 전기로의 전력 대비 감축량이 높게 나타났다. 실제 선택에는 고철 확보, 제품 품질, 합탕 여부와 설비 조건이 추가로 필요하다.

### 요금 개편과 부하 관리

공식 시간표와 개편 단가를 적용한 결과, UCI 사업장의 연 청구액은 약 3.3% 감소했다. 전기로 기본 시나리오는 1,403억 원에서 1,395억 원으로 약 0.6% 감소했다. UCI 결과는 소규모 사업장의 방법 시연이며 포스코 절감률로 해석하지 않는다.

## 8. 자체발전과 감축 비용의 영향

### 자체발전 감소를 함께 볼 필요

공정 전환 시 신규 설비의 전력만 계산하면 준비해야 할 구매 전력을 작게 볼 수 있다. 자체발전이 감소하는 경우를 따로 계산해 전력 확보 부담이 얼마나 달라지는지 살펴봤다.

| 자체발전 감소율 | 추가 구매 전력 | 연 전력비용 | 순 감축 |
|---|---|---|---|
| 0% | 0.79 TWh | 1,395억 원 | 301만 t |
| 5% | 1.69 TWh | 2,984억 원 | 264만 t |
| 15% | 3.48 TWh | 6,164억 원 | 189만 t |

전기로 기본 시나리오에 감소율만 바꾼 보고값이다. 자체발전 감소율 0~30%는 실제 감소 예측이 아니라 가정 축이다. 현업 적용에서는 부생가스 발생량과 발전 계획을 확보하는 일이 우선이다.

### 무엇을 기준으로 비용을 비교하는가

| 감축 조치 | 탄소 1t 감축당 전력비용 | 적용 규모 |
|---|---|---|
| 전기로 전환 | 약 4.6만 원 | 전기로 생산 175만 t |
| 기존 구매와 전기로 전력을 직접 PPA로 전환 | 약 8.7만 원 | 전력 약 3.84 TWh |
| 수소환원 전력을 전부 직접 PPA로 공급 | 약 39.9만 원 | 수소환원 생산 100만 t |

쇳물 1t을 싸게 만드는 방법과 탄소 1t을 싸게 줄이는 방법은 다를 수 있다. 수소환원제철은 전력망 수전해가 생산 단위 비용은 낮지만, 감축량이 작아 감축 1t당 전력비용은 그린수소 방식보다 약 3.1배 높았다.

전기로·수소환원 값은 추가 전력비용을 감축량으로 나눈 지표다. 고로 원료비 절감과 투자비가 빠져 있으므로 전체 전환비용이나 투자 수익률과 구분한다. 직접 PPA 전환은 기존 전력 구매 대비 추가 비용을 사용한다. 서로 다른 비용 범위를 확인하며 우선 검토 대안을 고르는 용도로 활용한다.

## 9. AI 응답 평가와 개선 결과

질문은 계산 가능한 경우, 정보가 부족한 경우, 지원 범위를 벗어난 경우로 구성했다. AI가 알맞은 도구를 부르고 계산 결과를 정확히 설명하는지 점검했다. 평가 정답은 계산기 출력이며 일부 문항은 손계산으로 추가 대조했다.

| 평가 구분 | 초기 33개 평가 | 추가 17개 평가 |
|---|---|---|
| 정상 계산 질문 | 최초 7/18, 질문 문장 수정 후 18/18 | 13/14 |
| 정보 부족 질문 | 8/8 되묻기 | 2/2 되묻기 |
| 범위 밖 질문 | 7/7 답변 유보 | 1/1 답변 유보 |

별도로 작성한 처음 보는 질문 3개도 모두 통과했다. 두 평가 기록을 합치면 정상 질문 31/32, 정보 부족 10/10, 범위 밖 8/8이다. 다만 전체 50개를 한 번의 동일 조건으로 평가한 결과와는 구분한다.

### 무엇이 개선되었는가

처음에는 "N01 조건"이나 "S1"처럼 앞 문맥을 알아야 하는 질문이 있었다. 질문마다 새 대화를 사용하자 AI가 조건을 되물었다. 이를 독립적으로 이해할 수 있는 문장으로 고친 뒤 정상 질문 18개가 통과했다.

추가 평가의 N21은 답변 내용과 숫자는 맞았지만 자동 채점기가 "비용이 낮다"를 추천 표현으로 인식하지 못했다. N31은 표본 수를 AI가 바꿔 호출해 결과가 달라졌다. 기본 표본 수를 유지하도록 도구 설명을 수정한 뒤 통과했다.

### 평가 결과의 의미

이번 평가는 계산 도구의 결과를 AI가 올바르게 전달하는지 확인한 것이다. 시뮬레이터 자체의 현실 적합성은 별도 검증이 필요하다. 질문당 한 번씩 호출한 결과를 통해 수정한 문항과 도구 설명도 있다. 출처 인용 정확도는 아직 측정하지 않았다.

다음 평가에서는 개선에 쓴 질문과 별도 평가 질문을 나눈다. 반복 실행으로 응답의 일관성을 확인하고, 현업 질문과 인용 정확도도 점검한다.

## 10. 현업 활용과 향후 개발 방향

### 계획 담당자가 얻는 효과

사용자는 감축 목표를 전력 확보 목표로 바꿔 볼 수 있다. 확보량이 부족하면 추가 계약이 필요한 양과 대안 조건을 확인한다. 비용이나 배출계수가 바뀌어도 같은 계산으로 다시 비교할 수 있다. 담당자들이 같은 기준으로 대안을 검토하고 계산 과정을 설명하는 데 도움이 된다.

| 단계 | 개발 방향 | 확인할 결과 |
|---|---|---|
| 현재 시제품 | 공개 자료와 계산 도구를 자연어 웹앱으로 연결 | 전력·비용·탄소 계산과 조건부 추천 |
| 사내 시험 | 사내 LLM 연결과 실제 계약·실측 자료 적용 | 모델 교체 후 응답과 계산 기준 확인 |
| 병행 검토 | 기존 업무의 계산 결과와 읽기 전용 비교 | 오차 원인과 업무 활용성 확인 |
| 의사결정 지원 | 권한 관리·근거 검색·이력 저장 강화 | 담당자가 검토 가능한 추천과 근거 |

### 우선 확보해야 할 데이터

| 자료 | 확장되는 기능 |
|---|---|
| 설비별 15분 부하와 실제 계약·청구 | 현장 조건에 맞는 요금·부하 계산 |
| 부생가스 발생량과 자체발전 계획 | 전환에 따른 구매 전력 증가량 구체화 |
| 설비 투자비와 원료비 절감 | 총비용과 투자 타당성 비교 |
| 시간별 재생전력·저장·수소 공급 계획 | 부족 시간대와 운전 대안 분석 |
| 사내 문서와 배출권 할당 자료 | 내부 근거 검색과 실제 업무 기준 반영 |

보안을 고려한 최종 방향은 사내 서버에서 모델과 계산기를 운영하는 것이다. 계산 엔진과 AI 연결부를 나눴으므로 사내 모델로 교체하는 구조를 유지한다. 접근 권한, 기록 보관, 데이터 외부 전송 통제는 실제 도입 환경에 맞춰 검증한다.

현재 시제품은 연간 전력량 기준이다. 시간별 공급과 저장을 연계하면 향후 전력 부족 시간대를 확인하는 방향으로 발전시킬 수 있다. 최종 설비·조달 결정은 담당자의 검토를 거쳐 수행한다.

### 개발 흐름

주제와 사용 상황 정리 → 공개 자료 수집 → 탄소와 전력 계산식 구현 → 필요량과 부족량 파악 → AI와 웹앱 연결 → 적합한 공정 선택 → 평가 및 오류 보완 → 조달 대안 비교 기능 확장

11월 9일에는 계산 기준을 정리하고 목표 구축, 전력량 계산, AI 연결을 진행했다. 11월 10일에는 공식 요금 시간표를 반영하여 그린수소 비교, 감축 비용 분석, 평가 질문 50개로 범위를 확장했다.

### 개발 과정에서 얻은 결과

숫자를 계산 코드가 책임지도록 하면서 AI의 역할을 질문 이해와 결과 설명에 집중시켰다. 근거가 약한 자체발전 감소율은 숨겨진 기본값보다 비교 조건으로 드러내는 편이 계획 검토에 유용했다.

전력 부족량을 알려주는 기능에서 출발하여 "어떤 조건을 얼마나 바꾸면 목표에 도달하는가"를 제시하는 기능으로 발전했다. 그린수소와 전력망 수전해의 비교도 단순 추천보다 목표 충족 여부와 갈림길 조건을 함께 제시하는 방향으로 구체화했다.

### 최종 결과와 남은 과제

우리 팀은 탄소 목표와 현장 조건을 입력하면 전력 및 비용을 계산한다. 이때 현장 조건에 맞는 공정을 제공하는 AI 어시스턴트의 시제품을 구현했다. 공개 자료로 계산 구조와 질문 응답 흐름을 확인했다.

다음 단계는 사내 실측과 계약 자료로 입력값을 구체화하고, 기존 계획 수립 방식과 나란히 비교하는 것이다. 이를 통해 계산의 정확성과 추천의 실무 활용성을 확인하여 내부 서버 기반 의사결정 지원 도구로 발전시키고자 한다.

기본값은 전력배출계수 0.4173 tCO₂eq/MWh, 수소환원 전력 3,720 kWh/t, 전기로 전력 450 kWh/t다. 고로 대체 기준 1.99 t/t는 회사 평균 역산값이다. 전기로 직접 배출 0.08 t/t는 고철 기반 값이므로 광양의 합탕 조건을 적용하려면 보완이 필요하다.

자체발전 감소율은 0~30% 시나리오로 열어 둔다. 기본 발전 감소 0%가 실제 전환 때 감소가 없다는 뜻은 아니다. 회사가 발표한 전기로 순감축 1.4 t/t는 기본 상향식과 별도 시나리오로 비교한다.

수소환원 손익분기 전력배출계수 0.535는 이 보고서의 원단위와 대체 기준에서 계산한 값이다. Bhaskar 논문의 약 0.456과는 적용 기준이 다르다. 몬테카를로의 비율은 가정한 분포의 표본 비율이며 현실의 성공 확률이 아니다.

## 부록 2. 추가 분석과 검증 기록

### 시간별 전력 분석

2025년 전력거래소 시간별 자료를 이용한 분석에서 경부하 시간의 전력 배출은 연평균보다 약 0.7% 높았다. 전기요금이 싼 시간으로 옮기는 것만으로 탄소가 줄어드는 것은 아니므로 요금과 배출을 나누어 살펴봤다.

연간 재생전력량이 같아도 필요한 시간에 공급되는 양은 달랐다. 전국 발전 프로필 기준 태양광은 수전해 전력의 약 47%, 태양광·풍력 반반 조합은 약 72%를 같은 시간에 채웠다. 이를 적용한 순 감축은 쇳물 1t당 각각 약 0.94 t와 1.22 t로 계산됐다. 실제 사업장의 공급 보장값이 아닌 분석 조건의 결과다.

### 추천 민감도 분석

기본 국내 조건에서 한 변수씩 바꾸면 PPA 계약 단가와 한전 요금 변화가 추천을 바꾸는 주요 조건으로 나타났다. 여러 조건을 함께 바꾼 표본 중 그린수소가 저렴한 비율은 국내 조건 약 43%, EU 수준 탄소 가격 조건 약 99%였다. 이 비율은 가정한 분포와 표본 수에 따른 결과다.

2030년 낙관 가정으로 배출계수 0.245를 적용하면 그린수소가 유리해지는 탄소 가격은 약 14.9만 원/t로 높아졌다. 전력망 자체가 깨끗해질수록 전력을 바꿔 얻는 추가 감축 효과가 작아지기 때문이다. 이는 미래 예측이 아닌 가정 시나리오다.

### 검증을 나누어 해석

| 검증 구분 | 확인 내용 |
|---|---|
| 입력과 내부 정합성 | 숫자 입력·허용 범위 검사, 단위와 산식 점검 |
| 외부 자료 대조 | 요금표 9종과 시간표, 문헌 원단위 및 논문 조건 대조 |
| 평균값 참고 비교 | 전기로 평균 요금 약 177원/kWh와 산업용 평균 181.9원 비교 |
| AI 응답 평가 | 계산 숫자 전달, 되묻기, 지원 범위 안내 확인 |

산업용 평균 단가와 가깝다는 사실은 독립적인 정확도 보증이 아니다. 외부 AI 검토 의견도 수정 방향을 찾는 참고로 활용했다. 현실 적합성은 사내 실측과 경계가 일치하는 자료로 추가 확인한다.

### 결과 재현과 관리

계산기 검증, 부하 분석, 경로 비교, 목표 역산, 질문 세트, 자체발전 분석, 감축 비용 분석을 각각 실행본으로 관리했다. AI 평가는 도구 호출과 답변 전문을 기록하며, 원문의 reports/평가결과.jsonl을 평가 기록으로 사용한다.

대표 실행: `python3 analysis/05_검증.py` → `python3 analysis/09_질문세트.py` → `python3 analysis/14_평가.py`. AI 연결과 평가는 Claude Code 설치 및 로그인이 필요하다. 원문 기재 환경은 Python 3.14.6과 pandas 3.0.5다.

추가 확정 항목은 참고 문헌의 정식 서지정보, 실제 계약 요금과 부생가스 발전 영향, 투자비·원료비 자료, 현업 인터뷰, 인용 정확도 평가다. 제출 전 팀이 보유한 원문과 실행 기록을 기준으로 최종 확인한다.
